# Grip Food

เว็บไซต์สั่งอาหารภาษาไทยสำหรับลูกค้า ร้านอาหาร และผู้ดูแลระบบ

## เปิดใช้งาน

- เว็บไซต์: https://grip-food-ui.vercel.app
- หน้าเข้าสู่ระบบ: https://grip-food-ui.vercel.app/login
- หน้าสมัครสมาชิก: https://grip-food-ui.vercel.app/register
- หน้าร้านและผู้ดูแลระบบ: เปิด `?role=merchant` หรือ `?role=admin` ต่อท้ายลิงก์เข้าสู่ระบบ

## เทคโนโลยี

HTML, CSS และ JavaScript มาตรฐาน ทำงานบน browser ไม่ต้องติดตั้ง package; หน้าแยกใช้ rewrites จาก `vercel.json`

## ขอบเขตระบบปัจจุบัน

เว็บไซต์นี้เป็น prototype สำหรับนำเสนอขั้นตอนและหน้าตาการใช้งาน ข้อมูลบัญชี เมนู คำสั่งซื้อ และการชำระเงินยังทำงานใน browser เท่านั้น ข้อมูลกลับค่าเริ่มต้นเมื่อ reload และการเข้าสู่ระบบยังตรวจบัญชีที่กำหนดไว้ในโค้ด ยังไม่มี API, ฐานข้อมูลถาวร, การเก็บรหัสผ่านอย่างปลอดภัย, ผู้ให้บริการ OTP, การรับชำระเงินจริง หรือ GPS ไรเดอร์จริง อย่าใช้กับลูกค้าหรือรับชำระเงินจริงก่อนเชื่อมระบบเหล่านี้
